# 输出与视觉规范

只在规划交付件、检查页面或修改构建器时读取本文件。

## 默认文件

| 文件 | 用途 | 必需 |
|---|---|---|
| `复习资料.md` | 可编辑、可搜索的内容主交付 | 是 |
| `题库.json` | 练习题与答案的结构化副本 | 是 |
| `复习资料.html` | 单文件离线阅读与答题 | 是 |
| `sources.json` | 材料与定位方式 | 是 |
| `verification.json` | 核验状态与未解决问题 | 是 |
| `复习资料.pdf` | 打印与平板批注 | 可选 |

若没有选择题，`题库.json` 可以是空数组，但必须说明原因。若资料只完成部分章节，文件名不必改变，页面元信息必须标“阶段稿”。

## `subject.json`

```json
{
  "title": "课程名 · 期末复习",
  "out_html": "复习资料.html",
  "out_json": "题库.json",
  "out_md": "复习资料.md",
  "out_pdf": "复习资料.pdf",
  "quiz_cats": ["概念辨析", "公式理解", "步骤判断"]
}
```

`quiz_cats` 恰好三个。不同学科可以改中文类别，但内容中的 `cat=` 必须匹配。

## 视觉语言

- 暖米白纸张背景；
- 陶土橙 `#D97757` 为主强调色；
- 深墨正文、白色卡片、浅灰边框与轻阴影；
- 侧栏目录、卡片、网格纸和批注感；
- 820px 以下切换移动端单栏；
- 不通过给 `html` 或 `body` 设置 `overflow-x:hidden` 掩盖溢出问题。

视觉服务于长文阅读，不宣称它能提高学习成绩。

## 交互与离线

- 选择题点击后显示对错与解析；
- 按二级标题统计本节正确率；
- 页面底部显示全局答题进度；
- 本地图片内嵌为 data URI；
- 不加载 CDN、远程字体、分析脚本、模型 API 或第三方页面；
- 打印时隐藏导航和交互按钮，显示答案与解析。

## 题库 JSON 字段

```json
{
  "id": "ch01-q01",
  "belong_to": "第一章",
  "category": "概念辨析",
  "question": "题干",
  "options": ["A. …", "B. …", "C. …", "D. …"],
  "answer": "C",
  "explanation": "解析、依据与核验说明"
}
```

不增加没有读取方的分数、难度或预测概率字段。

## 目检

至少检查：

1. 首页与目录；
2. 最密集的公式或表格；
3. 一张带图片的题卡（如有）；
4. 移动端宽度；
5. 打印预览中的分页、答案和中文字体。

PDF 小于 50KB 通常可能是浏览器错误页，构建脚本会拒绝采用。

# 来源与核验

只在登记材料、处理冲突或执行发布前核验时读取本文件。

## `sources.json`

```json
{
  "course": "概率论与数理统计",
  "scope_note": "第1—5章；第6章不考",
  "sources": [
    {
      "id": "S01",
      "type": "textbook",
      "title": "教材名称",
      "edition": "第5版",
      "local_file": "教材.pdf",
      "locator": "印刷页码",
      "coverage": "第1—5章",
      "rights": "用户提供，仅本地整理"
    }
  ]
}
```

`local_file` 只写相对文件名或用户看到的材料名，不写个人绝对路径。`rights` 记录处理依据，不代表对外再分发授权。

## 定位优先级

1. 印刷页码；
2. PDF 页码（明确写“PDF页”）；
3. 章节与节名；
4. 课件页码；
5. 真题年份、卷别与题号；
6. 无法精确定位时写“定位待补”，不得估算页码。

正文统一使用 `📖 [S01 p.23]`、`📖 [S02 第3章第2节]` 或 `📖 [S03 2023A 第5题]`。

## `verification.json`

```json
{
  "status": "in_progress",
  "checks": [
    {
      "id": "ch01-q01",
      "kind": "quiz",
      "source": "S03 2023A 第5题",
      "first_pass": "passed",
      "second_pass": "passed",
      "notes": "独立计算结果一致"
    }
  ],
  "unresolved": []
}
```

状态只使用 `in_progress`、`passed`、`blocked`。单项核验使用 `passed`、`failed`、`pending`。

## 核验方法

### 事实和定义

- 回到原材料定位；
- 检查限定词、适用范围和例外；
- 同一术语在不同材料中含义不同时，分别标注。

### 公式

- 核对符号、下标、分母、自由度和成立条件；
- 用一个满足条件的简单数值做量纲或边界检查；
- 不用“常见写法”覆盖指定教材写法。

### 题目

- 检查题干数据是否自洽；
- 从空白开始求解；
- 逐个检查干扰项，保证只有一个正确选项；
- 第二次核验应尽量与第一次分离；无法分离时如实标为 `pending`。

### 冲突

把冲突写进 `unresolved`，包含两个来源、冲突内容、影响范围和需要用户确认的问题。冲突解决前，不把对应题目计入已验证题库。

## 发布前快速反证

- 任抽 5 个考点，能否在材料中定位？
- 任抽 5 道题，从零解答能否得到同一答案？
- 删除网络后，HTML 是否仍能阅读和答题？
- 缺少浏览器时，Markdown、JSON 和 HTML 是否仍完整可用？
- 输入没有真题时，成品是否仍错误声称“高频”“必考”或“命中率”？
